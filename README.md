# Titanic Dataset Analysis & Report

## 📌 Project Overview
This repository contains an exploratory data analysis (EDA) of the famous Titanic dataset. The project investigates passenger survival factors based on demographics, socio-economic class, and other key variables using Python and data visualization libraries.

---

## 📂 Repository Structure
- `titanic_survival_report.pdf` - The final 3-page comprehensive report documenting the findings and data insights.
- `analyse.py` (or Jupyter Notebook) - The core Python script used for data cleaning, preprocessing, and generating visualizations.
- `assets/` - Contains generated plots and graphs (`graph1.png`, `graph2.png`) used in the report.

---

## 📊 Key Insights
- **Gender Disparity:** Female passengers had a significantly higher survival rate compared to male passengers due to evacuation priorities.
- **Socio-Economic Impact:** First-class passengers experienced much better survival probabilities than third-class passengers.
